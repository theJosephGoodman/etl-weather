# DAG по ежедневной записи погоды в городе Владикавказ(респ. Северная Осетия-Алания)

*Логика работы:* python скрипт автоматически работает на базе Airflow. Каждый день делается запрос к открытому API с данными о погоде. Данные слегка предобрабатываются(из http-ответа достается контент) и затем загружаются в базу данных Postgres
